# Private pilot evidence template

Copy this blank template to approved private operational storage. Never fill in
personal details in the repository, Jira, CI artifacts or public reports. Mark
unperformed checks UNVERIFIED, with the missing prerequisite and responsible role.
Use pseudonymous references in any aggregate report; keep the mapping private.

| Gate | Actual evidence to retain privately | Result / time / reference |
| --- | --- | --- |
| Baseline | Exact source, switches, current recovery receipt and capacity plan | UNVERIFIED |
| Participation | Willing employer/representative and candidate agreements; separate from analytics/email consent | UNVERIFIED |
| Authority | Official organisation/contact evidence and authority to advertise | UNVERIFIED |
| Onboarding | Current representative verification request/receipt and recipient inbox confirmation | UNVERIFIED |
| Reviewer | Existing authorised reviewer, different from submitting owner; no implied access grant | UNVERIFIED |
| Vacancy | Genuine role, official destination, future deadline and no applicant fee | UNVERIFIED |
| Review | Actor/time/reason and exact organisation/vacancy revision; correction and re-review evidence | UNVERIFIED |
| Publication | Eligibility, canonical source/date labels, public/sitemap metadata and no private fields | UNVERIFIED |
| Recovery | Duplicate/retry status handling, preserved records and switch-off procedure | UNVERIFIED |
| Expiry/withdrawal | Synthetic expiry regression; real closure/withdrawal only when it genuinely occurs | UNVERIFIED |
| Candidate usability | Consented participants attempted/completed, per-task elapsed time;8/10 within5minutes | UNVERIFIED |
| Manual access | Android/iOS browser/device, keyboard/focus/screen-reader findings and unresolved limitations | UNVERIFIED |
| Closeout | Actual flags, failures, aggregate counts, review limitations and remaining acceptance | UNVERIFIED |

Do not record passwords, security links or provider secrets. Provider acceptance is
not inbox delivery. A staff review is not a guarantee of authenticity/employment.
Configuration/counts alone cannot turn these gates into PASS. No retention duration
or lawful basis is invented by this template; follow the agreed private pilot policy.
