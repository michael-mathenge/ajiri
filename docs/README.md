cleanup. Consolidation removed 51 historical originals and added two current entry

## Historical material

Completed/outdated checkpoint reviews, decision forms, archive copies and the old
backend onboarding narrative are consolidated in one [maintenance history](../maintenance/HISTORY.md#how-to-use-this-file).
Their original files have been removed. Use its maintenance guide first and expand
dated records only when investigating previous decisions or evidence.

Current runbooks, the next-actions list and the active execution ledger remain
separate; old historical instructions do not authorize operations.
