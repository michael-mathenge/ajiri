affects minimatch versions 7 through versions below 11.0.1. GitHub Dependabot
alert32 remains open on the current default branch before this package's merge.
Both ESLint10.14.0 and config-array0.23.5 select minimatch10 through their published
ranges. Official npm registry queries on 13 November confirmed these are still the
latest upstream versions and that patched minimatch11.0.5 supports Node20 or>=22.

Two scoped npm overrides select exact minimatch11.0.5 for ESLint and config-array.
They do not override unrelated packages, downgrade ESLint, change CI, or weaken any
lint rule. The resulting graph deduplicates with the existing patched glob subtree.
Retain this temporary exception until a reviewed upstream range accepts the patched
major, then remove it while keeping the regression checks. This is development
tooling remediation, not a claim of an exploitable production application path.
